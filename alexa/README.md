# Skill "Monitor Inteligente" (pt-BR)

Nome de invocação: monitor inteligente. Intents: ConsultarTemperaturaIntent, ConsultarUmidadeIntent, ConsultarTHIIntent, ConsultarAmbienteIntent (143 frases de exemplo, nos CSV desta pasta), além dos intents padrão (Help, Stop, Cancel, Fallback).
Distribuída ao agricultor por teste beta do Alexa Skills Kit. O acionamento dos ventiladores por voz não passa pela skill: é feito pela integração do aplicativo Smart Life com a Amazon Alexa.
